## 5. Day 0 Operational Summary

### What Really Works Today
1. **Multi-Repo Architecture**:
   - `Shardrail_Core` builds, tests, and packages daemon, protocol, contracts, and client independently.
   - `Shardrail_Web` builds relay server and UI independently, consuming Core packages via git subtree tags without vendoring.
2. **Daemon & ACP Communication**:
   - `shardraild` spawns, controls, and inspects ACP agents via stdio using the mock agent harness.
   - Worktree isolation, session creation, command queuing, and turn-based interactions function reliably.
3. **Journal & Auditing**:
   - Immutable append-only event logging with monotonic cursors and epoch tracking.
4. **Relay Server**:
   - Pure WebSocket router handling machine pairing, daemon registration, browser subscriptions, and real-time event forwarding.
5. **Web UI**:
   - Complete browser SPA with zero-violation React Aria accessibility, pairing flows, markdown transcript rendering with HTML sanitization, live event streaming, and approval cards.
6. **Integration**:
   - Web + Core end-to-end integration verified: Web UI drives the Core release daemon and fake agent through full Playwright browser tests.
