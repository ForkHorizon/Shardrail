# T0.3 Create/Clean Shardrail_Web — Task Note

## Overview
This task cleans and restructures `Shardrail_Web` as an independent repository focused on the React web UI and the relay server per the approved `docs/tasks/T0.1-split-map.md`.

## Active Repository Scope Retained
1. **Web UI**:
   - Renamed from `apps/s5-prototype` to `apps/web` (`@shardrail/web`).
   - Removed legacy `src-tauri` directory.
   - Consumes `@shardrail/contracts` and `@shardrail/client` from `Shardrail_Core` via versioned subtree tags (`contracts-v0.0.1-import`, `client-v0.0.1-import`).
2. **Relay Server**:
   - `crates/relay` (Actix-web + Tokio WebSocket relay service).
   - Root `Cargo.toml` workspace updated to contain only `crates/relay`.
3. **Deployment**:
   - `deploy/` directory retained (`README.md`, `nginx-shardrail.conf`, `shardrail-relay.service`).
   - `deploy/README.md` updated with `apps/web` build commands and static file paths.
4. **Documentation & Plans**:
   - `PLAN.md` (single master plan and source of truth).
   - `AGENTS.md` (operational rules).
   - `docs/` (architectural specifications and task records).
   - `planning/` marked as archive via `planning/ARCHIVE.md`.

## Removed from Active Tree (Archived Non-Destructively)
- Prior to removal from `main`, the entire uncommitted/experimental repository state was preserved on remote branch `archive/pre-split-spikes` on `ForkHorizon/Shardrail_Web`.
- Removed from `main`:
  - `spikes/` (all historical worktrees, live scripts, logs).
  - `apps/s5-swift` (obsolete Swift CLI prototype).
  - `apps/web/src-tauri` (obsolete Tauri desktop scaffolding).
  - `archive/` (historical task snapshots).
  - `screenshots/` (UI run screenshots).
  - `crates/` (migrated to Core: `coordinator`, `fake-acp`, `journal`, `protocol`, `session-core`, `shardraild`).
  - `packages/` (migrated to Core: `contracts`, `client`).
  - `schema/` and `test-vectors/` (migrated to Core).
  - Obsolete monolith scripts: `check-schema-drift.sh`, `dev-try.*`, `s1-lite-*`.

## Package Consumption & Test Decoupling
1. **Core Package Integration**:
   - `apps/web/package.json` depends on:
     - `"@shardrail/client": "github:ForkHorizon/Shardrail_Core#client-v0.0.1-import"`
     - `"@shardrail/contracts": "github:ForkHorizon/Shardrail_Core#contracts-v0.0.1-import"`
   - Zero local type vendoring or copy-pasting.
2. **Self-Contained E2E Test Fixtures**:
   - Authored `apps/web/tests/fixtures/client-handshake-v1.json` replacing obsolete root `test-vectors/` reference.
   - Added `apps/web/tests/fixtures/fake_codex_app_server.py` and response fixture `codex-0.160.0-on-request-autowrite.jsonl` so browser tests can run independently with any `shardraild` daemon.
   - Updated `apps/web/tests/run-browser-e2e.mjs` with `NODE_OPTIONS="--import tsx"` for seamless TypeScript test execution under Node 22+.
3. **Independent CI Workflow**:
   - Rewrote `.github/workflows/ci.yml` with two decoupled jobs:
     - `relay`: Rust 1.84.0 fmt, clippy, cargo test, cargo deny.
     - `web-ui`: Node 22 npm ci, license check, Vite build, Vitest unit tests, Playwright browser E2E (downloads `shardraild` release binary from `ForkHorizon/Shardrail_Core` via `gh release download v0.0.1-import`).
